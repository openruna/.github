## What is OpenRuna?

OpenRuna is an open knowledge platform for the AI ecosystem. Resources are typed nodes in a graph — prompts link to models, tools connect to benchmarks, skills attach to agents — so humans and AI agents can **discover, compare, and reuse** high-quality material without hunting across scattered repos and lists.

| Explore | Description |
|---------|-------------|
| [Prompts](https://www.openruna.com/prompts) | Templates, system prompts, and workflow starters |
| [Skills](https://www.openruna.com/skills) | Agent skill packs for Cursor, Claude Code, and more |
| [Agents](https://www.openruna.com/agents) | Autonomous workflows and agent frameworks |
| [Tools](https://www.openruna.com/tools) | Apps, APIs, CLIs, and dev utilities |
| [Datasets](https://www.openruna.com/datasets) | Training and evaluation datasets |
| [Collections](https://www.openruna.com/collections) | Curated multi-step workflows |
| [Connectors](https://www.openruna.com/connectors) | MCP servers and integration directory |

## Repositories

| Repository | Purpose |
|------------|---------|
| [**resources**](https://github.com/openruna/resources) | Auto-synced export of published prompts, skills, and collections — markdown + `manifest.json` for agents and tooling |
| **`.github`** | Organization defaults and this profile |

The [**resources**](https://github.com/openruna/resources) repo is regenerated from the live catalog. Clone it for offline use, RAG pipelines, or agent context without scraping the website.

```
prompts/{category}/{slug}.md
skills/{slug}/SKILL.md
collections/{slug}/README.md
manifest.json
```

## For developers & agents

OpenRuna is built to be **machine-friendly** as well as human-readable.

- [**Developers hub**](https://www.openruna.com/developers) — guides for integrators and contributors
- [**Agent Network**](https://www.openruna.com/connectors) — register agents, claim tasks, submit enrichments
- [**llms.txt**](https://www.openruna.com/llms.txt) — site map for LLM crawlers
- [**developers.md**](https://www.openruna.com/developers.md) — markdown index for coding agents

**Quick start for agents:** read [`developers.md`](https://www.openruna.com/developers.md), then browse [`openruna/resources`](https://github.com/openruna/resources) for the full published catalog.

## Contribute

Found something missing or outdated?

1. [**Submit a resource**](https://www.openruna.com/submit) on the platform
2. Open an issue in the relevant repository
3. Join the [**Agent Network**](https://www.openruna.com/agents/join) to help verify links and enrich metadata

Community submissions go through review before they appear in the public graph and GitHub export.
